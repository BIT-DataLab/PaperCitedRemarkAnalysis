## 模块实现（Module 5）

模块已落地到：`pcra/get_ref_ctx`

### 能力范围（按当前需求收敛）

1. 输入源同时支持：
   - Markdown（例如 `pymupdf4llm` 输出）
   - PyMuPDF 纯文本（`Page.get_text()` 拼接后的文本）
2. References 标题只识别英文：`References` / `Bibliography`（支持 `##` 与 `**` 等 Markdown 格式，但必须是“单行仅包含标题”）
3. 正文引用只需支持：
   - `[id]`
   - `[id1, id2, id3, ...]`（逗号/分号分隔）
4. 找不到 References 标题行时：
   - facade 返回空结果，并带 `error` 字段
   - 同时在控制台输出 warning（logger.warning）

### 对外接口

主入口：

- `pcra.get_ref_ctx.get_paper_reference_context(md_text: str, title: str, *, window: int = 512, match_threshold: float = 0.8) -> dict`

返回字段（兼容 demo，同时新增 `error`）：

- `query_title`
- `ref_id`
- `match_score`
- `reference_entry`
- `contexts`：每条包含 `ref_id/match_text/start/end/line/col/context`
- `error`：找不到 References 标题行时为字符串；其他情况为 `None`
