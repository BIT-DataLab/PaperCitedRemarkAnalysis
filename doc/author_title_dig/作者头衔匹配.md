# openrouter联网功能调用

是的，**OpenRouter 的 API 本身确实支持联网搜索（Web Search）功能**，你可以通过 OpenRouter API 调用带有实时网络搜索能力的模型。([OpenRouter][1])

---

## ✅ OpenRouter 如何提供 Web Search + 模型回答

### 📌 1) `:online` 模式

OpenRouter 提供一个非常简单的方式 —— **在模型名称后加上 `:online` 后缀**：

```json
{
  "model": "openai/gpt-4o:online",
  "input": "请给我今天的主要科技新闻摘要"
}
```

加上 `:online` 后，模型会在生成回答时自动包含与查询相关的联网搜索结果（实时信息）。([OpenRouter][2])

这等价于启用一个 Web Search 插件（`plugins: [{ id: "web" }]`）的方式去抓取实时数据然后用它生成回答：([OpenRouter][2])

---

### 📌 2) `web` 插件

你也可以显式启用 Web Search 插件：

```json
{
  "model": "openai/gpt-4o",
  "plugins": [
    { "id": "web", "max_results": 5 }
  ],
  "input": "解释最新的人工智能法案进展"
}
```

这样，OpenRouter 会执行网络搜索并返回相关链接加内容，再由模型基于这些搜索结果回答。([OpenRouter][3])

---

## 📌 主要特点

✅ **可对任意支持的模型启用联网搜索**，不仅仅是 OpenAI 提供的，例如 DeepSeek、Anthropic 等也能加 `:online`。([OpenRouter][2])
✅ **返回中会带有 URL 引用 / 注释**（类似 GPT Web Search 的 citations）。([OpenRouter][2])
✅ **基于 Exa.ai 等搜索引擎**，也可以选择“native search”模式（如果模型提供商支持）或 fallback 到 Exa 搜索。([OpenRouter][2])

---

## 💡 费用和注意点

⚠️ **联网搜索是要额外计费的**——比如按照检索结果数量计费（例如 $4/1000 results 这样的计价，具体看你设置的搜索参数和 OpenRouter 计费）。([OpenRouter][2])
⚠️ **并非所有模型默认带搜索**；必须加 `:online` 后缀或启用 `web` 插件。([OpenRouter][1])

## 🧠 和 OpenAI 自家 web_search 方案的对比

| 特性       | OpenRouter                   | OpenAI 官方                            |
| -------- | ---------------------------- | ------------------------------------ |
| 联网搜索能力   | ✅ `:online` 或 `web` plugin   | ✅ Web Search / web_search_preview 工具 |
| 是否兼容多模型  | ✅ 是（OpenAI/Anthropic/others） | ❌ 仅限 OpenAI                          |
| 引用输出     | ✅ URL citations              | ✅ citations/sources                  |
| 是否需要额外配置 | 👍 只需后缀或插件                   | 👍 需在 tools 字段里指定                    |

简单来说，如果你想**统一一个 API 管理多家模型并支持联网搜索**，OpenRouter 是能做到的。([OpenRouter][2])
