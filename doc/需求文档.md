# **论文被引用语境评价分析系统

需求规格说明（简明版）**

## 1. 系统目标

构建一个自动化系统，用于分析**论文或作者论文在高影响力文献中的被引用语境及评价态度**，支持以下能力：

* 根据**论文标题或作者名**作为入口，获取目标论文集合
* 检索并筛选**高学术影响力论文**对目标论文的引用
* 自动解析引用上下文，并给出引用评价得分（0-10，越高越积极）
* 输出结构化结果，支持统计与分析（均值、分布、阈值统计等）

---

## 2. 输入形式

系统支持两类输入路径：

### 2.1 基于论文标题（Paper-based）

* 输入：

  * `paper_title: str`
  * `top_k: int`（相似度匹配数量，默认 3）
* 说明：用于定位目标论文的唯一标识（通常取最相似的一篇）

### 2.2 基于作者名（Author-based）

* 输入：

  * `author_name: str`
  * `top_k_papers: int`（可选）
  * `only_first_author: bool`（可选）
* 说明：用于获取作者的代表性论文集合

---

## 3. 系统功能模块

### 模块 1：论文标识检索

**目标**：将论文标题映射为唯一论文实体

* 数据源：OpenAlex
* 输入：论文标题
* 输出：

```json
matched_paper_list = [
  {paper_title, paper_doi, paper_id, year, authors}
]
```

---

### 模块 1.1：作者论文检索

**目标**：获取作者的高相关性论文列表

* 数据源：OpenAlex
* 输入：作者名、筛选参数
* 输出：

```json
author_paper_list = [
  {paper_title, paper_doi, paper_id, year, authors}
]
```

---

### 模块 2：被引关系检索与学术影响力筛选

**目标**：筛选“值得分析”的引用论文

* 数据源：OpenAlex
* 输入：

  * 被引用论文标识（title / DOI）
  * `citation_topK`
  * `h_index_threshold`
* 核心逻辑：

  * 获取引用目标论文的文献列表
  * 根据作者 **H-index 阈值**筛选高影响力论文
* 输出：

```json
gold_paper_list = [
  {
    paper_id,
    title,
    doi,
    authors: [{name, h_index}]
  }
]
```

---

### 模块 3：论文 PDF 获取

**目标**：获取引用论文全文

* 输入：论文标题 / DOI
* 数据源：公开搜索引擎
* 输出：

```text
pdf_file_path
```

---

### 模块 4：PDF 引用上下文抽取

**目标**：定位目标论文在引用文献中的被引用语境

* 输入：PDF 文件路径
* 核心能力：

  * 文本抽取
  * 引用标记识别（如 `[12]`, `(Author, Year)`）
  * 上下文片段提取
* 输出：

```json
contexts = [ctx1, ctx2, ...]
```

---

### 模块 5：LLM 引用评价评分

**目标**：对每条引用上下文进行评价打分

* 输入：引用上下文列表
* 输出：按上下文给出结构化评分结果（0-10）

```json
{
  "paper_id": {
    "paper_name" : "xxx"
    "contexts": [
      { "ctx": "...", "reason": "...", "remark_score": 8 },
      { "ctx": "...", "reason": "...", "remark_score": 5 }
    ]
  }
}
```

---

## 4. 系统输出

系统最终输出为**按被引用论文聚合的引用语境评价结果**，支持：

* 单篇论文的引用评价评分统计（均值 / 中位数 / 分布等）
* 可按分数段派生统计（例如 0-3 偏负面，4-6 中性/不明确，7-10 偏正面）

---

## 5. 约束与原则

* 仅使用**公开、合法、可自动化访问的数据源**
* 系统为**离线分析型 pipeline**，不要求实时性
* 优先保证可实现性与可解释性，而非评价评分的极致精度
