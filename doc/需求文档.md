# **1. 系统目标与输入输出**

## **1.1 系统目标**

对 “作者” 或 “论文” 的被引用语境进行自动化分析：

1. 根据作者找出其全部论文，并分析其被引用语境。
2. 根据 DOI / 标题直接分析单篇论文的被引用语境。

系统包含三大核心能力：

* 检索引用关系
* 抽取引用上下文
* 使用 LLM 进行语气判定（positive / normal / negative）

---

# **1.2 系统支持的两类输入路径**

## **A. Author-based Workflow**

| 字段                  | 类型   | 是否必需 | 描述            |
| ------------------- | ---- | ---- | ------------- |
| `author`            | str  | 可选   | 作者姓名（支持模糊匹配）  |
| `only_first_author` | bool | 可选   | 是否只分析第一作者论文   |
| `top_k_papers`      | int  | 可选   | 限制分析论文数量      |
| `top_k_citations`   | int  | 可选   | 限制每篇论文分析的引用数量 |

---

## **B. Paper-based Workflow**

| 字段            | 类型  | 是否必需 | 描述                |
| ------------- | --- | ---- | ----------------- |
| `paper_title` | str | 可选   | 模糊匹配论文标题          |
| `doi`         | str | 可选   | 若给定 DOI 则直接精确检索论文 |

> 规则：
> • 若提供 DOI → 走论文工作流
> • 若提供标题 → 走论文工作流
> • 否则 → 需提供 author，否则报错

# **2. 系统总体架构**

共 7 个模块（含入口解析）：

0. 输入解析模块（Input Dispatch）
1. 作者论文检索模块
2. 指定论文检索模块
3. 引用文献检索模块
4. 引用者资质筛选模块
5. 引用上下文抽取模块
6. LLM 情感判定模块
7. 结果分组与聚合模块（Aggregation with remark categories）

---

# **3. 模块定义**

## **3.1 模块 0：入口解析模块**

```
IF doi exists:
    workflow = PAPER
ELSE IF paper_title exists:
    workflow = PAPER
ELSE IF author exists:
    workflow = AUTHOR
ELSE:
    error("no valid input")
```

---

## **3.2 模块 1：作者论文检索模块**

数据源：

* OpenAlex（推荐）
* Semantic Scholar
* CrossRef
* Google Scholar（爬虫）

输出：

```
author_paper_list = [
  {paper_title, paper_doi, paper_id, year, authors},
  ...
]
```

---

## **3.3 模块 2：论文检索模块**

支持：

* DOI 直接检索
* 标题模糊匹配 + 相似度排序

输出格式同上。

---

## **3.4 模块 3：引用文献检索模块**

```
cur_citing_paper_list = [
  {
    "title": ...,
    "doi": ...,
    "paper_id": ...,
    "authors": [...],
    "year": ...,
    "pdf_url": ...,
    "references": [...],
    "full_text": ...
  },
  ...
]
```

---

## **3.5 模块 4：引用者资质筛选模块**

判断通过以下任一条件即可：

* 作者头衔：IEEE Fellow / ACM Fellow / AAAI Fellow
* 机构关键词：Google / OpenAI / DeepMind / FAIR
* H-index ≥ 阈值（例如 30）
* 白名单规则（whitelist）

通过 → 继续
未通过 → 跳过此引用

---

## **3.6 模块 5：引用上下文抽取模块**

解析典型格式：

```
[12]
(Author, YEAR)
Author (YEAR)
```

输出：

```
contexts = [ctx1, ctx2, ...]
```

---

## **3.7 模块 6：LLM 情感判定模块（positive/normal/negative）**

Prompt（示例）：

```
Given the citation contexts below, determine whether the tone
toward the referenced paper is positive / neutral / negative.
Return exactly one of: "positive", "normal", "negative".
```

输出：

```
remark = "positive" | "normal" | "negative"
```

---

## **3.8 模块 7：结果聚合模块（关键更新）**

系统需根据 remark 自动分类到 **3 个列表**：

```
remark_positive
remark_normal
remark_negative
```

### 聚合逻辑（伪代码）

```
result = {
  ...paper metadata...
  remark_positive: [],
  remark_normal: [],
  remark_negative: []
}

For each citing_paper:
    if remark == positive: append to remark_positive
    elif remark == normal: append to remark_normal
    else: append to remark_negative
```

# **4. 完整系统流程（新版分类输出）**

```
User Input
  ↓
Module 0: Input Dispatch
  ↓
IF Author Workflow → Module 1
ELSE → Module 2
  ↓
target_paper_list
  ↓
For each target paper:
      Module 3: retrieve citing papers
      Module 4: academic authority filter
      Module 5: citation context extraction
      Module 6: LLM remark classification
      → send to one of {positive, normal, negative}
--------------------------------------------
Module 7: grouped aggregation
  ↓
Output JSON (with remark_positive / remark_normal / remark_negative)
```
